What this comparison can tell us

Upstream Harness² already supplies execution trajectories to its improver. The diagnostics condition adds deterministic summaries from stored Agent Lens spans: explicit errors, repeated tool calls, latency, and deliverable presence. Grades and rubrics stay outside improvement contexts.

Each domain adapts on tasks 1–2. The adopted harness is frozen for task 3. There is one adaptation trajectory per condition/domain; judge variability and provider changes remain possible. Trace patterns describe operations and do not by themselves explain a score difference.

Costs include execution, improvement, reflection, retries, and judging, using frozen prices and provider usage. An incomplete campaign is labeled above. Downloaded records and span excerpts remain accessible when Agent Lens requires authentication.
